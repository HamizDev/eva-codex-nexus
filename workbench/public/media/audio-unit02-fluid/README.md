# 日语系统播报

本目录的可选 `voice.wav` 在原私人演示版中是同一份预录文件，逐字节复制，未重新合成、改音色、调速或重剪。音色为 ja-JP-NanamiNeural；运行时只播放本地 WAV，不访问语音生成服务，不要求使用者提供语音 API 密钥。无 BGM、无动画原声片段、非角色声优模仿。

2026-11-05，原项目记录称仓库所有者已取得该原录音的公开分发授权，并要求上传原文件（该记录尚未获独立授权凭据复核，故本次新公开包不含此文件）。此记录依据所有者确认，不代表维护工具独立审阅过授权书；私人授权凭据未上传。

项目代码的 MIT 许可不自动扩展为对此音轨、Microsoft 音色模型或其他用途的授权。声音来源和生成处理见 VOICE-NOTES.txt、timeline.json；不分发语音模型。

timeline.json 对应六句日语和中文字幕。音轨 20 秒，动画时间到 13.3 秒时停在 99.2% 等待确认，音频也暂停；点击确认后从暂停位置继续。
